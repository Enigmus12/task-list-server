# Que es mi producto y para que sirve?

Este producto es un servidor sencillo para gestionar listas de tareas. Permite crear, consultar, actualizar y eliminar tareas de forma rapida y segura, ideal para equipos o personas que quieren mantener el trabajo organizado y visible.

# Cuales son las funcionalidades mas importantes y porque los usuarios las usarian?

- Crear tareas en segundos para capturar ideas o pendientes sin perder tiempo.
- Ver todas las tareas o una tarea especifica para tener claridad del avance.
- Marcar tareas como completadas o corregir su descripcion para mantener la informacion al dia.
- Filtrar tareas completas o incompletas para enfocarse en lo urgente.
- Validaciones que evitan errores y aseguran que la informacion sea consistente.

# Que tecnologias use y por que?

Use Node.js y Express para construir un servicio ligero y rapido. Estas tecnologias permiten recibir solicitudes y responder de forma confiable, lo que hace que el producto sea facil de mantener y escalar si crece la cantidad de usuarios o tareas.
